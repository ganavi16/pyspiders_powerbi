# Retail Sales Analysis Dashboard -- Power BI

## 📊 Project Overview

This project is an interactive **Power BI retail sales dashboard**
designed to analyze business performance across regions, categories, and
time.

The report contains two main dashboard pages:

-   **Overview** -- high-level business performance with KPI cards,
    filters, regional analysis, category analysis, and detailed tables.
-   **Time Series Analysis** -- trend-focused analysis using time-based
    charts and supporting detail tables.

## 🎯 Project Objectives

The dashboard is designed to help answer questions such as:

-   How are sales performing across different regions?
-   Which categories contribute most to overall performance?
-   How does performance change over time?
-   Which areas of the business require further attention?
-   How can interactive filtering be used to explore the underlying
    retail data?

## 🛠️ Tools & Technologies

-   **Power BI Desktop**
-   **Power Query** for data preparation
-   **DAX** for calculations and measures
-   **Data Modeling**
-   Interactive slicers, KPI cards, charts, and tables

## 📑 Dashboard Pages

### 1. Overview

The Overview page provides a high-level snapshot of the retail dataset.

It includes:

-   KPI cards
-   Interactive slicers
-   Sales by region
-   Category-level analysis
-   Bar/column charts
-   Pie/donut-style visualizations
-   Detailed tables

### 2. Time Series Analysis

The Time Series Analysis page focuses on performance trends over time.

It includes:

-   Time-based KPI analysis
-   Trend line charts
-   Interactive date/filter controls
-   Detailed supporting tables
-   Multiple trend views for deeper analysis

## 🚀 How to Use

1.  Download or clone this repository.
2.  Open `Retail_store_Dataset.pbix` using **Power BI Desktop**.
3.  If Power BI asks for updated data-source paths, update them to the
    location of the dataset on your computer.
4.  Refresh the data if required.
5.  Use the slicers and visuals to explore the report.
